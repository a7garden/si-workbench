# lunch — 오전 결산

무인·읽기 전용 스킬이다. 사용자는 실행을 걸어둔 채 점심을 먹으러 갔을 수 있다.

## 무인 실행 계약

[UNATTENDED] 사용자는 자리를 비운 상태에서 이 스킬을 실행한다. 어떤 단계에서도 사용자에게 질문하거나 응답을 기다리지 않는다. 모든 판단과 근거는 마지막 보고에 적는다. 사용자 확인이 필요한 사항은 실행을 멈추지 말고 보고서에 "확인 필요"로 표시한다.

## 공통 원칙

- 이 스킬은 완전 읽기 전용이다. vault 노트, 저널, 코드베이스 어디도 수정/생성하지 않는다.
- 원격 저장소 변경 금지: `git push`, `svn commit`/`svn ci`, `git svn dcommit`, `hg push`는 실행하지 않는다.
- vault 경로 결정: `${user_config.vault_path}` → `%USERPROFILE%\.claude\si-workbench\config.json`의 `vaultPath` → 사용자 문의. 무인 실행이므로 어디서도 경로를 못 찾으면 질문하지 말고 실패 사유를 보고하고 종료한다.

## 절차

1. **오늘 노트 로드** — `${vault}/일지/YYYY-MM-DD.md`(로컬 날짜). 노트가 없으면 생성하지 말고 "오늘 노트가 없습니다 — `/si-workbench:morning`을 먼저 실행하세요"를 보고하고 종료한다.
2. **할 일 상태 파싱** — `## 오늘 할 일`의 체크박스 항목을 [x]/[ ]로 나눈다. 항목이 없으면 "오늘 할 일 비어 있음"으로 진행한다.
3. **오전 작업 수집** — 오늘 저널(`%USERPROFILE%\.claude\si-workbench\journal\<오늘>.jsonl`)에서 session_id dedup 후 유효 라인의 transcript마다 [SAMPLING] 규칙을 적용한다. 저널이 없거나 유효 세션이 없으면 "오전 세션 기록 없음"으로 진행한다.

[SAMPLING] transcript JSONL 샘플링 규칙: (1) 전체 통독 금지. (2) 먼저 라인 수 파악. (3) `"type":"summary"` 라인과 user 발화(`message.role == "user"`이고 content가 문자열이거나 content[].type=="text")를 추출. (4) 마지막 assistant 텍스트 1-2개만 추가. (5) tool_result 본문은 읽지 않는다. 파일이 크면 앞부분 user 발화와 뒷부분 마무리를 우선.

4. **대조** — 항목을 셋으로 분류한다: 완료([x]), 진행 중([ ]인데 저널에 해당 작업의 명백한 근거 있음), 미착수(근거 없음). 근거 판정은 항목 문구와 수집된 작업 내용이 명백히 일치할 때만 인정하고, 애매하면 미착수로 분류한다. 근거가 있으면 어느 세션/프로젝트(cwd)인지 출처를 함께 적는다.
5. **결산 출력** — 아래 형식 그대로 마무리한다:

```
오전 결산

완료:
- (항목)

진행 중:
- (항목 — 근거 출처)

미착수:
- (항목)

오후 제안: (미착수 항목 중 먼저 할 것과 한 줄 근거. 판단 근거가 없으면 목록만)
```

## 금지

- 어떤 파일도 수정/생성하지 않는다.
- 오후 제안을 질문으로 바꾸지 않는다. 제안 한 줄로 끝낸다.
